# Password_CrackingProject1-UM
This project demonstrates the concepts, techniques, and prevention methods related to password cracking and credential-based attacks in the field of Cybersecurity. The main objective of this project is to understand how attackers attempt to gain unauthorized access to systems using weak passwords, leaked credentials, and automated attack techniques.
The objective of this project is to spread awareness about credential security and help learners understand both offensive and defensive cybersecurity concepts responsibly and ethically. Some Objectives like
Test password strength 
Stimulate the cracking password 
Hashing 
Improve Awareness
